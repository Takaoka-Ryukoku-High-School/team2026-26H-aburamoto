# 今日の気候で決める、今日の行動

Python と Flet で作った、今日の気候に合わせて行動を提案するアプリです。都市名から Open-Meteo の天気予報を取得し、気温・降水確率・天候に応じた行動を表示します。提案はチェックリストに追加でき、完了状態はユーザーのホームディレクトリに保存されます。

## 起動方法

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

起動するとブラウザでアプリが開きます。

場所を入力して「天気を見る」を押すと、今日の予報に加えて、時間ごとの気温・降水確率・風速に合わせた朝・昼・夕方/夜のアドバイスと行動のヒントが表示されます。日本の都道府県名を入力した場合は、県庁所在地の天気を表示します。天気情報の取得にはインターネット接続が必要です。
